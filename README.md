# AnonymChat

A **real-time anonymous chat application** built with React and Firebase. Users can chat anonymously without revealing their identities, powered by Firebase's real-time capabilities.

## 🔗 Live Demo

[fir-chat-app-bbe20.web.app](https://fir-chat-app-bbe20.web.app/)

## ✨ Features

- 💬 **Real-time Messaging** — Instant message sync via Firebase Realtime Database
- 👻 **Anonymous Chat** — Chat without revealing personal identity
- 🔐 **User Authentication** — Firebase Authentication for session management
- 🗄️ **Message Persistence** — Messages stored in Firestore
- 🎨 **Material UI** — Clean interface built with MUI components

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|--------|
| React | Frontend framework |
| Firebase Auth | User authentication |
| Firestore | Message storage |
| Firebase Realtime DB | Real-time message sync |
| Material UI (MUI) | UI components |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/SarthakPaandey/AnonymChat.git
cd AnonymChat

# Install dependencies
npm install

# Configure Firebase
# Add your Firebase config to src/firebase.js

# Start development server
npm start
```
